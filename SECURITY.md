# Security policy

Report vulnerabilities privately to **aaitor@gmail.com**, or use private reporting in the Security tab if available. Include the affected commit, impact, and a minimal public/synthetic reproduction. Do not send credentials, private presenter footage, connection secrets, or customer data.

Security fixes target the latest default branch unless a release-specific policy is documented. This is a community-maintained project with no guaranteed response time. See [security and privacy](docs/security-and-privacy.md) for capture data, optional endpoints/GPU hosts, vendoring, and media rights.
